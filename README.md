# Engineering Project Archive

A complete, curated technical archive of my software engineering projects. This repository serves as a centralized documentation hub, transforming raw project repositories into structured engineering case studies.

## Architecture

This project is built as a minimalist, document-style React application emphasizing readability, technical accuracy, and clean information architecture.

- **Frontend:** React, Vite, TypeScript
- **Styling:** Tailwind CSS (configured for document-style typography and layouts)
- **Data Model:** Centralized, strictly typed metadata driving the entire application.

## Design Philosophy

The site eschews traditional "portfolio" aesthetics (large hero sections, card grids, heavy shadows) in favor of a clean, technical manual approach. Every project page functions as an objective case study documenting:

- The core problem and implemented solution
- Verified architectural decisions
- Factual technology stacks (Frontend, Backend, Database, Infrastructure)
- API and Data Model details

## Projects Documented

The archive currently indexes 11 projects across various domains:

- **Web Apps:** Geo-Watch, AASHA, WardWatch, Globe-Trotter, Mind-Meal, StaySplit
- **AI/Intelligent Systems:** DISPATCHOPS, Drill-Insight, Mob-Alert
- **Developer Tools:** GitGo, Arch-Flow
